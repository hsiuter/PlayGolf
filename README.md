# 高爾夫勝負計算器使用教學

這是一個給手機使用的離線優先高爾夫勝負計算網頁。第一次開啟後，資料會存在該裝置的瀏覽器本機資料庫，不需要後端伺服器。

網站網址：

```text
https://hsiuter.github.io/PlayGolf/
```

如果帳號有設定 GitHub Pages 自訂網域，也可能是：

```text
https://lianofficial.site/PlayGolf/
```

## 重要概念

- 本系統資料儲存在目前這台手機或電腦的瀏覽器內。
- 不同手機之間不會自動同步資料。
- 清除瀏覽器網站資料、換手機、換瀏覽器，都可能看不到原本資料。
- 建議定期到「設定」匯出 JSON 備份。
- GitHub Pages 上的版本只提供程式本身，不會保存你的個人場次資料。

## 加到手機主畫面

### iPhone Safari

1. 用 Safari 開啟網站。
2. 點下方分享按鈕。
3. 選擇「加入主畫面」。
4. 之後可從主畫面開啟。

### Android Chrome

1. 用 Chrome 開啟網站。
2. 點右上角選單。
3. 選擇「加到主畫面」或「安裝應用程式」。
4. 之後可從主畫面開啟。

## 計分頁

計分頁用來建立一場新的勝負紀錄。

### 選擇參賽者

1. 選擇本場人數：3 人或 4 人。
2. 在每個下拉選單選擇參賽者。
3. 若啟用中的參賽者少於 3 位，系統會提示無法建立場次。

### 輸入分數與桿數

每位參賽者有兩個欄位：

- 分數：用於分數勝負計算。
- 桿數：用於讓桿後的逐一對戰勝負。

桿數預設為 `80`。

你可以用三種方式調整數字：

- 直接點數字欄，用鍵盤輸入。
- 點 `-` 或 `+` 按鈕逐格調整。
- 在「左右滑動調整」區域左右滑動。

滑動方向：

- 向右滑：增加。
- 向左滑：減少。

### 查看勝負結果

輸入後系統會即時計算每位參賽者的勝負。

- 正數：贏，應收。
- 負數：輸，應付。
- 0：打平。

每個人的結果卡片可以點「明細」，查看：

- 分數勝負
- 讓桿勝負
- 對每位對手的逐一對戰結果

### 儲存本場

確認結果後，點「儲存本場」。

儲存後會移到「歷史」頁面。

## 歷史頁

歷史頁包含兩個主要區塊。

### 累計勝負

顯示每位參賽者目前累計勝負，並依累計金額排序。

如果曾匯入 Excel 歷史總表，這些歷史資料會納入累計，但不會在畫面上逐筆顯示。

### 新場次

顯示用本系統儲存的新場次。

每場會顯示：

- 日期
- 本場參賽者
- 每位參賽者的分數、桿數、勝負

如果輸入錯誤，可以點該場的「刪除」移除該場紀錄。

## 讓桿頁

讓桿頁用來管理參賽者與兩兩讓桿數。

### 新增參賽者

1. 在「新增姓名」輸入姓名。
2. 點「新增」。

同名防呆：

- 若已有啟用中的同名參賽者，系統會阻止新增。
- 若已有停用中的同名參賽者，系統會詢問是否重新啟用。

### 移除參賽者

點參賽者旁邊的「移除」。

移除是「停用」，不是永久刪除：

- 不會出現在計分選人和讓桿選單。
- 歷史紀錄仍保留。
- 累計勝負仍可保留原本資料。
- 之後可重新勾選啟用。

### 修改讓桿

1. 在「兩兩讓桿」區選擇球友 A 和球友 B。
2. 調整「A 對 B 讓桿值」。
3. 點「儲存讓桿」。

調整方式：

- 直接輸入數字。
- 點 `-` 或 `+`。
- 左右滑動調整。

系統會自動維護反向值。例如：

- A 對 B 是 `6`
- B 對 A 會自動是 `-6`

## 設定頁

設定頁包含倍率設定、備份、匯入與清空資料。

### 倍率設定

預設值：

- 分數勝負倍率：`20`
- 讓桿勝負倍率：`100`
- 單一對戰封頂：`1000`

修改後點「儲存設定」。

每場紀錄會保存當時使用的倍率設定。

### 匯出 JSON

點「匯出 JSON」可下載完整備份。

JSON 會包含：

- 參賽者
- 讓桿表
- 設定
- 新場次
- 匯入的歷史資料

建議定期匯出 JSON，避免換手機或清除瀏覽器資料後遺失。

### 匯出 CSV

點「匯出 CSV」可下載試算表可讀的紀錄。

CSV 適合用 Excel 或 Google Sheet 查看與對帳。

### 匯入 JSON 備份

如果你曾匯出 JSON，可以用「匯入 JSON 備份」還原資料。

匯入後會覆蓋目前這台裝置上的本機資料。

### 匯入 Excel 範本

如果你原本使用與範本相同格式的 Excel，可以直接匯入。

匯入後系統會：

- 讀取參賽者名單
- 讀取兩兩讓桿表
- 讀取歷史勝負總表
- 套用到本機資料
- 自動下載一份 JSON 備份

注意：

- Excel 格式需與範本相同。
- 匯入會覆蓋目前本機資料。
- 匯入後的歷史總表會納入累計勝負，但不會在歷史頁逐筆顯示。

### 清空本機資料

點「清空本機資料」會重設這台裝置上的資料。

會清除：

- 新場次
- 修改後的讓桿
- 設定
- 匯入資料

清空後會回到系統內建的範例資料。

## 計算規則

本系統目前支援 3 人或 4 人場次。

每位參賽者的總勝負由兩部分組成：

1. 分數勝負
2. 讓桿後逐一對戰勝負

### 分數勝負

公式概念：

```text
自己的分數 * (人數 - 1) - 其他人的分數總和
```

再乘上「分數勝負倍率」。

### 讓桿勝負

每位參賽者會逐一和其他人比較：

```text
對方桿數 + 自己對對方的讓桿值 - 自己桿數
```

再乘上「讓桿勝負倍率」。

單一對戰結果會套用封頂值，預設為正負 `1000`。

## 常見問題

### 為什麼換手機後資料不見？

資料存在原本手機的瀏覽器本機資料庫，不會自動同步。

請在舊手機先匯出 JSON，再到新手機匯入 JSON。

### 為什麼 GitHub 上看不到我的場次資料？

場次資料不會上傳到 GitHub。

GitHub Pages 只提供網頁程式，資料存在每個使用者自己的裝置。

### 匯入 Excel 後歷史總表不見了？

歷史總表已隱藏，不在畫面逐筆顯示。

但它仍會納入「累計勝負」計算，也會保留在 JSON/CSV 匯出中。

### 可以離線使用嗎？

網站第一次載入後會快取主要檔案。

建議加入手機主畫面後使用。若瀏覽器清除快取，可能需要重新連網開啟一次。

### 如何備份？

到「設定」點「匯出 JSON」。

建議在以下情況前先備份：

- 換手機
- 清除瀏覽器資料
- 大量修改讓桿
- 匯入 Excel 前
